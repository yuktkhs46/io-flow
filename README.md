# 産業連関フロー

総務省ほか「産業連関表」（e-Stat 公開）の取引基本表から、産業間のお金の流れを可視化するツールです。2005・2011・2015年（平成17－23－27年接続産業連関表）と2020年（令和2年産業連関表）を比較できます。

## 画面

| 画面 | 内容 |
|---|---|
| 全体フロー | 費用構成（中間投入・付加価値・輸入）→ 産業（総供給）→ 販路（中間需要・最終需要）のサンキー図。産業グループ単位／表の部門単位を切替 |
| 産業別フロー | 選んだ産業の購入先・付加価値内訳と販売先・最終需要。主要指標（付加価値率、輸入係数、影響力・感応度係数） |
| 取引マトリクス | 取引額・投入係数・逆行列係数のヒートマップ（対数目盛） |
| 波及効果 | 任意の産業に需要が増えたときの生産・粗付加価値・雇用者所得の誘発額（国内需要／輸出） |
| 影響力・感応度 | 影響力係数×感応度係数の散布図 |
| 経年比較 | 全体の増減、産業グループ別の推移、産業別の増減率、選んだ産業の推移、投入係数・取引額の変化 |

13部門・37部門・108部門と年（2005/2011/2015/2020）を切り替えられます。108部門は2020年のみ。

公開・運用の方針は [docs/PUBLISHING.md](docs/PUBLISHING.md) を参照。

## 使い方

```bash
pip install -r requirements.txt
python pipeline/fetch.py        # data/sources.json の表を e-Stat から取得 → data/raw/
python pipeline/build_data.py   # 解析・検証 → data/processed/io.json
python pipeline/build_web.py    # dist/io-flow.html（オフラインで開ける単一ファイル）
python pipeline/build_web.py --cdn   # ライブラリを CDN から読む版
```

`dist/io-flow.html` をブラウザで開くだけで動きます（サーバ不要）。

## データ処理

- 取引基本表（生産者価格評価表）の内生部門 n×n、粗付加価値行、最終需要列、輸入列を抽出（単位：10億円）。
- 行バランス（中間需要＋最終需要−輸入＝国内生産額）と列バランス（中間投入＋粗付加価値＝国内生産額）を検算。
- 逆行列は競争輸入型 `[I − (I − M̂)A]⁻¹`（M = 輸入 ÷ 国内需要）。公式の逆行列係数表と最大誤差 5×10⁻⁴ 以内（取引表の丸めによる差）で一致することを確認。
- 波及効果：国内需要 Δf のとき直接効果 = (1−mᵢ)Δf、生産誘発 Δx = B·直接効果。粗付加価値・雇用者所得はそれぞれの率を Δx に掛けたもの（第1次波及まで）。

## 構成

```
pipeline/fetch.py        データ取得
pipeline/build_data.py   Excel 解析・整合性検証・JSON 出力
pipeline/build_web.py    HTML 生成
web/                     ビューア本体（body.html / style.css / app.js、D3 v7 + d3-sankey）
vendor/                  同梱用ライブラリ
```
